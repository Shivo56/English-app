Leçon 2 — Les indispensables du bac

Section 1
🤔 C'est quoi un verbe irrégulier ?
💡 En français, tous les verbes au passé suivent une règle.

En anglais, les verbes réguliers ajoutent juste -ed : walk → walked.

Mais les verbes irréguliers changent complètement ! Il faut les apprendre par cœur 😅
📌 Les 3 formes :

Base → présent
Prétérit → passé simple
Participe passé → avec have/has

Section 3
🧠 Astuces pour mémoriser
🔁 Groupe 1 — Les verbes qui ne changent pas
put → put → put
Ces verbes sont pareils aux 3 formes. Facile !
✌️ Groupe 2 — Prétérit = Participe passé
have → had → had
say → said → said
make → made → made
find → found → found
buy → bought → bought
Les 2 dernières formes sont identiques !
🔀 Groupe 3 — Les 3 formes différentes
go → went → gone
begin → began → begun
write → wrote → written
Ceux-là, il faut les apprendre par cœur 😅
⚽ Astuce CR7
Ronaldo wins every match → Ronaldo won every match → Ronaldo has won everything 🐐
Section 4
💬 Exemples en contexte
go → went → gone
She went to school yesterday.
Elle est allée à l'école hier.
She has gone to Dakar.
Elle est partie à Dakar.
write → wrote → written
He wrote a letter last week.
Il a écrit une lettre la semaine dernière.
see → saw → seen
I saw Ronaldo score at the World Cup.
J'ai vu Ronaldo marquer à la Coupe du Monde.
buy → bought → bought
She bought a new phone.
Elle a acheté un nouveau téléphone.
